# TT LIVE コメントビューアー

TT LIVEの配信情報をリアルタイムで表示するコメントビューアーです。

## ✨ 機能

- リアルタイムコメント表示
- リアルタイムギフト通知
- TOP視聴者表示
- ライブいいね通知
- 参加通知

## 🚀 使い方

ページを開いて、TTのユーザーIDまたは配信URLを入力して「接続」を押してください。

URLから直接接続することもできます。

https://nmlyz.github.io/tt_comment/?username=ユーザーID

## 🔗 クエリ

### username

接続するTTユーザーを指定します。

?username=ユーザーID

TTのプロフィールURLも指定できます。

?username=https://www.tiktok.com/@ユーザーID

### giftMute

ギフト通知音のON/OFFを指定します。

giftMute=0 → 音あり

giftMute=1 → ミュート

例：

https://nmlyz.github.io/tt_comment/?username=ユーザーID&giftMute=1
